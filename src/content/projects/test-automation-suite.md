At **FLUX Inc.** I engineered a hybrid automation suite that drove firmware
regression tests over SSH, replacing an error-prone manual setup process. The
tooling combined **Python** orchestration with **Bash/Expect** for interactive
session control, so engineers could launch a full regression run with a single
command.

The result was a dramatic reduction in turnaround time and a measurable drop in
human error during the firmware release process.
